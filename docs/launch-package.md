# Launch Package Plan

Status: Draft for Milestone 13.

The public launch should feel like discovering an absurdly complete artifact:
site, repo, build log, calibration data, firmware, CAD, media, and first-pour
story all ready at once.

## Launch Checklist

- Final README.
- Final build docs.
- Final calibration data and charts.
- Final CAD/scan/PCB artifacts or documented omissions.
- Final media assets.
- Launch video.
- Weekly video release queue.
- Social captions.
- Final site.
- License review for software, docs, CAD, media, and brand assets.
- Public repo review.
- Site publish.
- First Oaktown Labs social post.

## Required Readiness Questions

- Can a reviewer understand what was built?
- Are safety, food-path, alcohol, power, and tool notes visible?
- Are unknowns and failures preserved instead of hidden?
- Are generated changes reviewed before merge?
- Does the first viewport make The Negroni Pony obvious?

## Open Launch Dependencies

- Completed physical build.
- Final photos and video.
- Final calibration data.
- Final firmware/hardware artifacts.
- Final license scope.
- Final Oaktown Labs visual identity.
