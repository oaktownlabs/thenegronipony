# Glass Recess Plan

Status: Draft for Milestone 9.

The glass recess locates the rocks glass under the Nostril Nozzle while keeping
the lake base cleanable and visually intentional.

## V1 Intent

- Rocks glass only.
- Glass center aligns below the nostril pour point.
- Recess or insert should be wipeable.
- Cutting the original base is a later decision, not a planning assumption.

## Unknowns

- Target rocks glass dimensions.
- Base/lake material.
- Available depth for an insert or recess.
- Pour alignment after nozzle geometry is known.
- Splash behavior.
- Whether a removable insert is preferable to modifying the original base.

## Prototype Sequence

1. Select target glass.
2. Measure glass base diameter and taper.
3. Measure lake/base area and nostril-to-glass geometry.
4. Prototype removable insert first.
5. Test water pour alignment.
6. Test red-liquid splash visibility and wipe-down.
7. Decide whether the original base needs cutting.
