# Art Measurement Plan

Status: Template for Milestone 4.

Measure the object with enough care that CAD, drilling, glass recess, and media
planning can refer to the same facts.

## Tools

- Tape measure.
- Calipers.
- Flexible ruler or contour gauge if available.
- Painter's tape for temporary labels.
- Camera or phone.
- Notebook or direct repo notes.

## Measurement List

- Overall horse/lake dimensions.
- Base/lake top surface dimensions.
- Glass recess candidate area.
- Distance from nostril pour point to intended glass center.
- Nostril spacing and visible geometry.
- Potential umbilical entry/exit locations.
- Candidate UI placement area for selector, screen, and PONY POUR button.

## Recording Rules

- Record units with every value.
- Mark approximate values clearly.
- Photograph each measurement setup.
- Do not convert rough measurements into design constraints without review.
