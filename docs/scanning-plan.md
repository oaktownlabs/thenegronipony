# Scanning Plan

Status: Template for Milestone 4. Capture has not started.

The scan is a preservation artifact and a fabrication aid. Scan first, drill
last.

## Capture Sets

- Full sculpture and lake base.
- Muzzle and nostril close-up.
- Base/lake top surface.
- Underside and seams if accessible.

## File Naming

Use date-prefixed names:

- `scans/raw/YYYY-MM-DD_full-object_raw.*`
- `scans/raw/YYYY-MM-DD_nostril-closeup_raw.*`
- `scans/raw/YYYY-MM-DD_base-lake_raw.*`
- `scans/processed/YYYY-MM-DD_full-object_clean.*`
- `scans/processed/YYYY-MM-DD_nostril-test-section.*`

## Capture Notes

- Photograph the setup before scanning.
- Record scanner/app/software name and version.
- Record lighting conditions and any tracking problems.
- Keep raw files even if the first pass is ugly.

## Acceptance Criteria

- Raw full-object scan is archived.
- Raw nostril close-up scan is archived.
- Processed working mesh exists.
- Nostril-region test section is extracted for print/fabrication testing.
- Scan results are summarized in `docs/scan-results.md`.
