# Execution plans

Keep multi-PR feature plans here. Each plan records the approved requirements,
scope/exclusions, acceptance criteria, ordered PR slices and dependencies,
verification, progress, decisions, and unresolved questions. Small fixes may
keep their plan in the PR description.

Current rollout: [Independent review](2026-09-10-independent-review.md).

Existing canonical product plans elsewhere in the repository remain canonical;
link them from scoped plans rather than replacing them.
