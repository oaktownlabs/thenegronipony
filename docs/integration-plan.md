# Integration Plan

Status: Draft for Milestone 11.

Integration connects horse, lake base, sidecar, controls, lighting, pumps,
firmware, tubing, and cleaning workflow.

## Entry Criteria

- Sidecar water test complete.
- Nostril Nozzle fitted to original or validated final test setup.
- UI and lighting prototype tested off-sculpture.
- Pump calibration data exists for the installed pump/tube setup.
- Cleaning process has a draft procedure.

## Test Sequence

1. Dry fit horse/lake module and sidecar.
2. Route the 24-inch umbilical.
3. Connect controls and lighting.
4. Run water-only pump test.
5. Run colored-water pour test.
6. Run actual Negroni test after water behavior is safe.
7. Run cleaning cycle.
8. Run 10-pour repeatability test.
9. Test transport/setup/breakdown.
10. Document failure modes.

## Failure Modes To Watch

- Leaks at bottle, pump, umbilical, or nozzle.
- Tube kinks.
- Pump calibration drift.
- Glass misalignment.
- Drips after pour.
- Lighting/control faults near liquids.
- Cleaning process that is too annoying to repeat.
